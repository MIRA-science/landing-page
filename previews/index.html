How should the schema live on the landing page?

We're choosing how the MIRA schema graph — questions, claims, evidence, studies, protocols, requests — should appear on the landing page. Below are three candidates. Each one is the full landing page with a different treatment applied.

Tip: every preview has a switcher in the bottom-left corner — flip between versions without coming back here.
